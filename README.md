# 森屿时光

把一段专注时间变成城市里的一砖一瓦。这是一个可以在浏览器运行的首个可玩原型：专注计时、专注点、程序生成的世界、城市建设与升级构成完整的基本循环。

## 启动

在项目目录打开终端，运行：

```sh
node server.mjs
```

用浏览器打开终端显示的本地地址。需要已安装 Node.js。请通过本地服务器访问，不要直接双击 HTML 文件。

## 怎么玩

1. 给本次专注起一个任务名，设置时长，再开始计时。也可以暂停、继续或放弃。
2. 完成计时后获得专注点：每完成 1 分钟专注获得 1 点；提前结束不会发放本次奖励。暂停期间不计入专注时间。
3. 在建设面板选择设施，点击地图上的可建造位置，使用专注点建设城市。建造受地形、费用和城市等级限制。
4. 拖动地图浏览世界，滚动鼠标滚轮缩放。选择拆除工具，再点击已有建筑即可拆除。
5. 城市发展会提升人口与经济指标，达到条件后升级，解锁更多设施。图鉴可以查看设施与解锁要求。
6. 在统计界面查看每日专注时间和历史记录。声音面板提供森林、雨声和轻柔琴声；第一次播放需要点击按钮，音量可以调整。

地图包含山地、湖泊、河流与可建设陆地，通过程序生成，支持继续向外探索。道路、住宅、社区服务及港口等设施让城市逐步成形；行人和船只为城市增添生活气息。环境音由 Web Audio 实时合成，无需下载音频素材。

## 存档

数据保存在当前浏览器的本地存储中。刷新页面后可以继续；换浏览器、换本地地址、使用隐私模式或清除网站数据可能导致读不到原来的存档。请使用应用内的导出功能备份，恢复时导入备份文件。

当前没有账号系统、服务器数据库或跨设备同步。请不要把浏览器本地存储当作唯一的长期备份。

## 当前范围

这是第一版可玩的产品原型，采用温柔的二维城市画面，重点验证“专注 → 获得点数 → 建城 → 解锁”的体验。它不是完整的《我的世界》式三维世界模拟；交通、人口与经济使用简化模型，设施经营、完整产业链和更细致的城市生活可以在后续版本继续扩展。

浏览器后台标签页可能受到系统节能策略影响，声音也可能被系统暂停；建议专注时保留页面，并在长时间离开前导出存档。
